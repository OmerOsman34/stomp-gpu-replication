Methodology

The Matrix Profile

The Matrix Profile is a novel data structure that stores the distance to the nearest neighbor subsequence for every subsequence in a time series:

\[MP[i] = \min_{j \neq i} \text{ED}(Q_i, Q_j)\]

where: - \(Q_i\) = subsequence of length \(m\) starting at position \(i\) - ED = Euclidean Distance - \(n\) = time series length

Key Innovation of STOMP: Computes this in O(n²) time independent of m using First-Order Differences and incremental calculations.
